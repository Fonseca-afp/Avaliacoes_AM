# Military Academy – Physical Assessment Management App

This repository contains the full documentation and data model for an application designed to manage, record, and analyse the physical assessment results of cadets at the Military Academy.  
The project demonstrates structured software design, database modelling, and clear documentation aligned with professional development standards.

---

## 🎯 Purpose of the Application

The main goal of this application is to streamline the process of registering, storing, and reviewing physical assessment results for cadets.  
It aims to replace manual or fragmented processes with a unified, reliable, and secure digital system.

---

## 🧩 Key Features

- Record physical assessment results for each cadet  
- Manage cadet information (course, branch, role, etc.)  
- Ensure data consistency through controlled enums  
- Visualise assessment history  
- Export data for analysis  
- Provide a structured backend ready for future integration with a mobile or web app

---

## 🏛️ System Architecture (Conceptual)

The application is designed with a modular architecture:

- **Frontend (future)**: Web or mobile interface for instructors  
- **Backend (future)**: API to manage cadet and assessment data  
- **Database (current)**: Relational model designed in DBML and exported to SQL
